# Project Summary
This project is a web application designed to enhance the role-playing game experience by generating and managing custom equipment sets. Users can create tailored loadouts based on criteria such as budget and character archetypes, resulting in a structured and immersive gameplay experience. The application promotes diverse and balanced character builds through detailed equipment selection rules, ensuring that players can optimize their gameplay. Recent updates include the generation of 300 equipment sets with budgets ranging from 275 to 684 sp, achieving 99.5% budget efficiency while adhering to enhanced equipment combination rules.

# Project Module Description
The main functionalities of the project include:
- **Equipment Generation**: Create equipment sets based on user-defined budgets and parameters, adhering to specific rules.
- **Filtering and Browsing**: Users can explore various equipment options.
- **Support for Budget Tiers**: Accommodates different budget levels to suit various character builds, with weapon selection influenced by budget progression.
- **Enhanced Budget Management**: New logic ensures that users can efficiently spend their entire budget while adhering to equipment selection rules.
- **New Equipment Types**: Added mail chausses and demi-chausses, with specific rules for their use under plate armor.

# File Description Inventory
- **equipment_sets.md**: A markdown file that lists generated equipment sets, including their attributes and prices, organized by budget tiers. The file reflects new weapon selection rules and improved budget management.
- **equipment_sets.txt**: A compact text file that provides a concise summary of generated equipment sets, including budget and a comma-separated list of equipment items.
- **generate_sets.py**: Python script that generates the equipment sets according to updated rules for equipment selection and ordering, including budget-based progression for weapon types and enhanced logic for budget exhaustion.
