## How to use

The `.txt` files use a very compact format:
  `#001 [275sp] Palfrey, War Saddle, Lance, ...`

The `.md` files contain the full tables with slot / item / price.

These are full kits (weapons + armor + horse + accessories) following the same
historical compatibility rules used in the character generator's 3-phase equipment system.
