CRPG Rules – Consolidated Version (Updated)
Reference Date: June 9, 2026 (updated from original March/May 2026 snapshot)

Core Concept:
- Fully random character creation (everything is generated randomly, including origin, settlement, magic, gods, equipment, spells, magic items)
- Level support (-l / --level)
- Output: detailed CSV with specific columns + optional PDF character sheets (fiches/)

=== STARTING CAPITAL (pièces d'argent) ===
Capital de départ = **2,5 ans de salaire médian local (région + settlement) × niveau du personnage** × variance (0.8-1.2)

- Base: ~50 sp par niveau pour un perso "moyen" (calibré sur la médiane des salaires régionaux)
- Avec 2,5 ans: cible médiane ~125 sp pour niveau 1
- Formule dans regional_economy.py:
  daily_wage = get_median_daily_wage(region, settlement)
  base = daily_wage * 300 * 2.5 * level
  capital = int(round(base * random.uniform(0.8, 1.2)))
- Theoretical max (niveau 1): ~893 sp (Lantan + Metropolis + max variance)
- Min possible ~22 sp → Magic item budget max ~439 sp
- Kit de base régional fourni gratuitement (ne réduit pas le capital)
- "Magic_Item_Capital" = max(0, (900 - Starting_Capital) // 2)  → budget pour objets magiques de départ

CSV columns related:
- Starting_Capital
- Magic_Item_Capital
- Armes_et_Bouclier (inclut maintenant les objets magiques de départ)
- Prebuilt_Kit_Tier / Prebuilt_Kit_Cost_Sp

=== MAGIC SYSTEM ===
Seuil: MAGIC_THRESHOLD = -1.5  → ~50% de personnages magiquement actifs

determine_magic_type basé sur Combat_Points:

- Si combat_points >= -1.5 → Non-magique
- Roll pour type:
  - ~47% Théurgique (divine)
    - Subtype selon settlement:
      - Temple/urbain → Magie Blanche (guérison, protection)
      - Forêt/jungle/druid → Magie Verte (nature)
      - Sinon 60/40 Blanche/Verte
  - ~40% Arcanique → subtype "Magicien"
  - ~13% Sauvage (couleurs: Blanche/Rouge/Verte/Bleue/Noire)

Pour Arcanique/Magicien (niveau 1):
- 6 sorts niveau 1 connus aléatoires pondérés par fréquence (de sorts_mage_niveau_1_frequence.txt)
- Sélection sans remise, poids = popularity (1-5)

Objets magiques de départ:
- Budget = max(0, (900 - Starting_Capital) // 2) sp
- Sélection aléatoire (shuffle + greedy) depuis "starting magic items.txt" (tous <450 sp)
- Ajoutés à la colonne Armes_et_Bouclier dans le CSV (format "Nom (XX sp)")
- Projectiles légers magiques par pièce (pas en lots de 10) : Arrows/Crossbow Bolts/Sling Bullets/Javelins/Darts +1 (11 sp Uncommon), +2 (40 sp Rare), +3 (130 sp Very Rare). Idéal pour persos bas-capital / orientés Projectiles.
- Filtrage intelligent selon le kit :
  - Si le kit ne contient AUCUNE arme à distance (pas de bow/crossbow/sling/javelin/dart) → seulement les magic sling bullets, darts ou javelins.
  - Si le kit contient une arme à distance → uniquement les munitions magiques correspondantes ("the right magic ammunitions") : arrows pour arc, crossbow bolts pour arbalète, sling bullets pour fronde, etc. (javelins/darts restent souvent autorisés comme armes de jet flexibles).
- Les autres objets magiques (potions, wands, packs génériques Ammunition +x (10x), etc.) ne sont pas affectés par ce filtrage.

Magic_And_Spells (colonne CSV):
- Uniquement les sorts pour les Magicien (séparés par " | ")
- Les objets magiques sont maintenant dans Armes_et_Bouclier

=== GOD / DIVINITY SYSTEM ===
Utilise les fichiers:
- data/magic/gods_by_region.tsv
- data/magic/gods_by_ethnie.tsv

Logique choose_god(ethnicity, region_name, settlement_type, magic_type, magic_subtype):
1. Pool = dieux de l'ethnie OU de la région (listes classées par dévotion/rang)
2. Poids = 21 - rank (rang 1 très fréquent, rang 20 rare)
3. Bonus intersection (dieu fort dans les deux listes) ×1.7
4. Influence settlement:
   - Urbain (metropolis, major trade...) → Waukeen, Gond, Oghma...
   - Rural → Chauntea, Silvanus, Mielikki...
   - Coastal → Umberlee, Valkur...
   - Mountain/Dwarven → Moradin...
5. Biais magic:
   - Arcanique → ×4 sur dieux arcanistes (Mystra, Azuth, Savras, Velsharoon, Leira, Oghma, Deneir, Milil, Corellon, Labelas, Sehanine), ×0.18 sur les autres
   - Théurgique → ×1.2 + garantie (jamais "None")
   - Sauvage → biais nature/sauvage
6. Si pas de match culturel → garantie pour Théurgique (Silvanus/Chauntea ou premier de la liste)

Théurgique a TOUJOURS un dieu.

=== KITS D'ÉQUIPEMENT (100 kits system) ===
- Kit universel de survie gratuit (0 coût)
- Puis sélection du kit 100 le plus cher abordable avec le capital
- Fichier choisi dynamiquement:
  - Théurgique + Magie Verte (druides) → 100_Kits_Druide_Complete_100kits.txt (pas d'armure métal, focus nature)
  - Arcanique / Magicien → 100_Magician_Kits .txt (pas d'armure, focus ranged + crossbows, spell components)
  - Default → 100_kits_XV_siecle_Cote_des_Epees_EN (1).txt
- Résultat dans: Armes_et_Bouclier, Prebuilt_Kit_Tier, Prebuilt_Kit_Cost_Sp

=== COMBAT POINTS (non-linéaire) ===
CP par capacité (x brute) :
- x > 1 → x**1.4
- x < 0 → - ( (-x)**0.7 )
- x = 0 ou 1 → x

Total CP = sum CP capacités + CP_racial (de race_data)

Skill Modifier = - (Total CP + Secondary Points) / something (négatif = malus)
