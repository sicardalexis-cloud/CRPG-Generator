# GUIDE DE GÉNÉRATION DES COMPÉTENCES (SKILLS)
# Fichiers principaux : skill_data.py + knowledge_data.py + language_data.py

================================================================================
1. COMPÉTENCES PRIMAIRES : OUTDOOR + URBAN  (skill_data.py)
================================================================================

## 1.1 Détermination du NOMBRE de compétences

### Outdoor Skills Count (get_outdoor_skill_count)

Selon le type de settlement :

**Big Urban** (metropolis, major port/trade city, capitale, underdark city, dwarven fortress, elven enclave) :
- random.choices([0, 1, 2, 3], weights=[35, 35, 20, 10])
  → 0 : 35%
  → 1 : 35%
  → 2 : 20%
  → 3 : 10%
  (très faible en ville)

**Medium** (large town, fortified city, small town, ville moyenne, bourg) :
- random.choices([1, 2, 3, 4], weights=[25, 35, 25, 15])
  → 1 : 25%
  → 2 : 35%
  → 3 : 25%
  → 4 : 15%

**Rural / Villages / Camps / Outposts** (tout le reste) :
- random.choices([3, 4, 5, 6], weights=[15, 25, 35, 25])
  → 3 : 15%
  → 4 : 25%
  → 5 : 35%
  → 6 : 25%

### Urban Skills Count (get_urban_skill_count)

**Big Urban** :
- random.choices([3, 4, 5, 6], weights=[15, 25, 35, 25])
  (beaucoup de skills urbaines)

**Medium** :
- random.choices([2, 3, 4], weights=[25, 40, 35])

**Rural** :
- random.choices([0, 1, 2], weights=[40, 35, 25])
  (peu de compétences urbaines à la campagne)

## 1.2 Construction du POOL et Sélection

### Outdoor Pool (priorités fortes)

1. **Biais ethnique** (le plus important) :
   - ethnicity_outdoor_bias[ethnicity]  (liste de 3-6 skills typiques de l'ethnie)

2. **Biais régional** :
   - region_outdoor_bias[region_id]  (skills typiques de la région)

3. **Aléatoire très limité** :
   - random_count = 1
   - Si le pool actuel < (outdoor_count + 1) :
     → on ajoute seulement le nombre nécessaire de skills random depuis outdoor_skills_list (42 skills au total)

Puis :
selected_outdoor = random.sample( pool , min(outdoor_count, len(pool)) )

### Urban Skills

- Utilise `_weighted_sample_unique(URBAN_SKILLS, URBAN_WEIGHTS, urban_count)`
- Pondération forte sur les compétences "rue / underworld" :
  - Streetwise (Urban Underworld) : 25
  - Urban Stealth & Shadowing : 22
  - Urban Observation and Tailing : 20
  - Disguise & Impersonation : 17
  - Sleight of Hand & Cheating : 14
  - ... jusqu'à High Society Manipulation : 3

- Échantillonnage SANS REMISE (pas de doublons).

## 1.3 Total Primary Skills

total = outdoor_count + urban_count
Ce total est passé à generate_secondary_skills (active_count) et influence le nombre de langues bonus.

2. COMPÉTENCES SECONDAIRES (knowledge_data.py)
================================================================================

## 2.1 Craft Count

_calculate_craft_count() :
- return random.randint(1, 3)
→ Toujours entre 1 et 3 crafts.

Pondération :
- Base weights (craft_weights) : de 22 (Masonry) à 2 (très spécialisés)
- Modifiers : ethnicity_craft_modifiers + region_craft_modifiers + settlement_craft_modifiers
- final_weight = max( base + bias * 1.65 , 0.5 )
- Puis weighted_sample_without_replacement

## 2.2 Knowledge Count

_calculate_know_count(outdoor_count, urban_count) :
    total_primary = outdoor_count + urban_count
    know_count = 8 - total_primary
    return max(0, min(8, know_count))

→Nombre de compétences de connaissances = 8 - (outdoor + urban)
Résultat entre 0 et 8 (généralement 2-5).

Pondération similaire aux crafts mais avec multiplicateur plus fort :
final_weight = max( base + bias * 2.4 , 0.8 )

## 2.3 Literacy Count (langues écrites)

_calculate_literacy_count(know_count, settlement_type, ethnicity) :

base = 0
if know_count >= 3: base = 1
if know_count >= 4: base = 2

# Bonus settlement
if "metropolis" / "large city" / "capital" → base = max(base, 1)

# Bonus ethnies éduquées (si base==0)
educated = Chondathan, Tethyrian, Calishite, Mulan, Sun Elf, Gold Dwarf
→ base = 1

return min(4, base)

Règles spéciales dans la génération :
- 95% du temps : la première langue écrite est une langue déjà parlée
- Thorass est très accessible pour les humains éduqués
- On peut ajouter Thorass même s'il n'est pas parlé dans certains cas

## 2.4 Langues Parlées (language_data.py)

generate_languages(ethnicity, region_id, skill_modifier):

1. Langue ethnique de base (1 langue obligatoire)
   - ethnicity_base_languages[ethnicity]

2. Langue régionale
   - 75% de chance d'ajouter get_regional_language(region_id) (si pas déjà présente)

3. Langues bonus
   - bonus_count = know_count // 2   (arrondi à l'inférieur)
     où know_count = 8 - (outdoor + urban)
   - Pour chaque bonus :
     - 85% de chance d'ajouter une langue du pool (ethnicity_bonus + region_bonus)
   - Évite les doublons

Exemples :
- know_count=2 → bonus_count=1
- know_count=3 → bonus_count=1
- know_count=4 → bonus_count=2
- know_count=5 → bonus_count=2
- know_count=0 ou 1 → bonus_count=0

================================================================================
RÉSUMÉ DES NOMBRES CLÉS
================================================================================

**Outdoor count :**
- Big city : 0-3 (forte chance 0-1)
- Medium : 1-4
- Rural : 3-6

**Urban count :**
- Big city : 3-6
- Medium : 2-4
- Rural : 0-2

**Craft :** 1-3 (uniforme)

**Knowledge :** 8 - (outdoor + urban)   [min 0, max 8]   (somme outdoor+urban+know ≈ 8)

**Literacy (écrit) :** 0-4 (fortement lié à knowledge + urbanisation + ethnie)

**Spoken languages :**
- Base : 1 (ethnique)
- + ~75% régional
- + (know_count // 2)  avec 85% de chance par bonus
  (know_count = 8 - (outdoor + urban) ; floor div)

Le système est conçu pour que :
- Les ruraux aient beaucoup de outdoor + peu d'urban
- Les urbains aient beaucoup d'urban + peu d'outdoor
- Les persos avec beaucoup de skills primaires (outdoor+urban) aient MOINS de connaissances (trade-off)
- know_count = 8 - (outdoor + urban)
- Les crafts (1-3) restent indépendants
- Le nombre de langues bonus dépend maintenant du nombre de connaissances : bonus = know // 2
- Literacy dépend fortement du nombre de connaissances + urbanisation + ethnie
